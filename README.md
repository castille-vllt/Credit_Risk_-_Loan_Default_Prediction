# Credit_Risk_and_Loan_Default_Prediction
This project analyzes a loan dataset to assess credit risk and predict loan defaults. It includes:

Exploratory Data Analysis (EDA): examines relationships between borrower characteristics, FICO scores, interest rates, debt-to-income ratio, and loan outcomes.
Data preprocessing: prepares numerical and categorical variables for machine learning.
Model comparison: trains and compares Ridge and Lasso Logistic Regression, Random Forest, and Decision Tree models.
Model evaluation: uses Accuracy, Precision, Recall, F1-score, AUC, MSE, ROC curves, confusion matrices, and 5-fold cross-validation.
Feature importance: identifies the variables that contribute most to default prediction.
Hyperparameter tuning: optimizes the Decision Tree using GridSearchCV.
Business risk grading: converts predicted default probabilities into A–G risk grades.
Business application: translates the predictions into potential automated approvals, manual reviews, and high-risk loan rejections, supporting a more risk-aware lending strategy.
